Sistem Analisa & Eksekusi Otomatis Crypto (Spot & Futures)

Spot Market Futures Market

1. Konsep & Tujuan Sistem

Sistem ini dirancang sebagai Web-Based Trading Dashboard pribadi yang responsif. Tujuannya adalah menghilangkan emosi dalam trading, meningkatkan kecepatan eksekusi, dan mempermudah pemantauan pasar 24/7.

Fitur Inti

  • Market Monitor: Mengambil data harga (Real-time WebSocket & REST API).
  • Analyzer Engine: Menghitung indikator teknikal (RSI, MACD, Bollinger Bands) secara otomatis.
  • Signal Generator: Memberikan notifikasi "BUY/LONG" atau "SELL/SHORT" berdasarkan logika yang ditentukan.
  • Auto-Executor (Bot): Opsi untuk mengeksekusi order secara otomatis ke Exchange (Binance/Bybit).
  • Position Management: Trailing stop, Auto Break Even, dan Take Profit bertahap.

2. Teknologi yang Digunakan (Tech Stack)

Pemilihan teknologi difokuskan pada kecepatan (latency rendah), kemudahan pengembangan (Python), dan aksesibilitas (Web).

Komponen Teknologi Alasan Pemilihan
Backend API Python (FastAPI) Sangat cepat (Asynchronous), ekosistem data science/finansial yang kuat (Pandas, TA-Lib).
Exchange Connector CCXT Library Library standar industri untuk koneksi ke ratusan exchange crypto.
Database Utama PostgreSQL Relasional, kuat untuk data transaksi dan user config.
Data Caching Redis Menyimpan data harga real-time (ticker) untuk akses super cepat tanpa membebani DB utama.
Frontend React.js / Next.js Component based, SPA (Single Page Application) yang cepat dan responsif.
UI Framework Tailwind CSS Mempercepat styling responsif (Mobile First).
Scheduler Celery / APScheduler Untuk menjalankan job berkala (misal: scan market setiap 15 menit).

4. Alur Kerja Sistem (Workflow)

Berikut adalah logika langkah demi langkah bagaimana bot bekerja dari mengambil data hingga menutup posisi.

1. Data Ingestion
Sistem menarik data Candle (OHLCV) terbaru dari Exchange.
2. Indicator Calculation
Hitung RSI, MACD, EMA, dll menggunakan library (pandas-ta).
3. Strategy Check
Looping logika: IF RSI < 30 AND Price> EMA200 THEN...
4. Risk Validation
Cek saldo, hitung lot size (Risk 1-2%), cek max open positions.
5. Execution (Entry)
Kirim Order API (Limit/Market) + Set Stop Loss awal.
6. Monitoring (Active)
Pantau harga live. Geser SL ke Break Even jika profit > X%.
7. Exit / Take Profit
Tutup posisi saat target tercapai atau kena SL. Simpan log ke DB.

5. Rancangan Database (Schema)

Struktur tabel SQL yang disarankan untuk menyimpan konfigurasi dan riwayat trading.

Tabel: `configurations`

Menyimpan setting API dan preferensi global.

  • id (PK)
  • exchange_name (varchar) - e.g., 'binance'
  • api_key (text, encrypted)
  • api_secret (text, encrypted)
  • is_trading_active (boolean) - Master Switch
  • max_risk_per_trade (float) - e.g., 1.0 (persen)

Tabel: `strategies`

Menyimpan parameter strategi yang bisa diubah via Web UI.

  • id (PK)
  • name (varchar) - e.g., 'Scalping RSI'
  • timeframe (varchar) - e.g., '15m', '1h'
  • symbol_list (json) - e.g., ['BTC/USDT', 'ETH/USDT']
  • parameters (json) - e.g., {"rsi_period": 14, "buy_threshold": 30}

Tabel: `trades`

Mencatat setiap posisi yang diambil.

Column Type Description
id UUID Primary Key
symbol Varchar Pasangan koin (BTC/USDT)
side Varchar LONG / SHORT
market_type Varchar SPOT / FUTURES
entry_price Decimal Harga masuk
exit_price Decimal Harga keluar (nullable)
size Decimal Jumlah koin/kontrak
pnl Decimal Profit/Loss dalam USDT
status Varchar OPEN, CLOSED, CANCELED
entry_time Timestamp Waktu masuk
exit_time Timestamp Waktu keluar

Tabel: `logs`

Untuk debugging sistem (Error API, Logic execution).

7. Panduan Keamanan (PENTING)

Karena ini menyangkut uang, keamanan adalah prioritas mutlak.

1. API Key Restrictions

Saat membuat API Key di Binance/Bybit, HANYA centang "Enable Reading" dan "Enable Futures/Spot Trading". JANGAN PERNAH centang "Enable Withdrawals".

2. Environment Variables

Jangan pernah *hardcode* API Key di dalam kode script. Gunakan file `.env` yang tidak di-upload ke git.

DB_PASSWORD=rahasia123

3. Kill Switch (Panic Button)

Buat tombol fisik atau digital di dashboard yang berfungsi untuk "Close All Positions & Stop Bot" seketika jika terjadi bug atau pasar crash.
