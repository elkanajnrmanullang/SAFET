# [SAFET]

Sistem analisis dan eksekusi otomatis untuk pasar Cryptocurrency (Spot & Futures).

Proyek ini adalah platform berbasis web responsive yang dirancang untuk penggunaan pribadi (personal use). Sistem berfungsi untuk memantau pergerakan pasar secara real-time, melakukan analisis indikator teknikal otomatis, serta memberikan keputusan aksi (seperti Entry, Stop Loss, dan Take Profit) pada akun exchange yang terhubung.
